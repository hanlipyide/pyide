# 用Python轻松做桌面软件

很多人不是没有想法，而是被“搭界面、配环境、接事件、做打包”这一长串流程挡在了门外。

PyIDE 把这条路变成一个更直接的体验：**免安装、免部署，拖拽搭出界面，用 Python 写逻辑，最后一键打包成 Windows 应用。**

它是一款为中文用户打造的可视化 Python 桌面 IDE。你不必在界面设计器、代码编辑器、Python 环境和打包工具之间来回切换；打开 PyIDE，就可以从一个空白窗口开始，把想法一步步变成可以运行、可以分享的 `.exe` 软件。

**免安装 Python，免配置开发环境，免部署运行环境，一键打包 Windows `.exe`。**

![PyIDE 工作区：拖拽设计界面，编写 Python 逻辑](pyide-workspace.png)

## PyIDE 特别在哪里？

### 不是只能写代码的编辑器，而是一套完整的做软件流程

从窗口布局到控件属性，从按钮事件到 Python 逻辑，再到最终打包，PyIDE 把桌面应用开发中最常用的环节放在同一个工作区里。先把界面摆出来，再让代码为它注入行为，边做边运行、边改边看效果。

### 不是只能拖控件的演示工具，而是 Python 驱动的真实应用开发

按钮、输入框、文本框、容器和布局都可以通过属性面板调整；控件之间的交互、数据处理和业务逻辑，仍然使用熟悉的 Python 完成。做出来的不是一张静态界面，而是可以运行的桌面程序。

### 免安装、免部署，把时间留给真正的功能

PyIDE 内置 Python 运行环境，解压后即可使用，无需单独安装 Python，也无需手动配置开发环境。打包时将运行所需内容一并整理到成品中，减少在目标电脑上重复部署环境的麻烦。

### 中文优先，学习和使用都更顺手

菜单、控件属性和常见提示都围绕中文用户设计。代码补全、悬浮提示、定义跳转和代码诊断，帮助你少查资料、少走弯路，把注意力放回真正想做的功能上。

## 三步，把想法变成软件

1. **搭界面**：拖入控件，调整大小、位置、文字和属性。
2. **写逻辑**：为控件连接事件，用 Python 实现交互和功能。
3. **一键打包**：调试完成后，生成可分发的 Windows `.exe` 应用。

适合制作桌面小工具、学习项目、内部工具、原型应用，以及任何“我想把这个 Python 想法做成软件”的项目。
